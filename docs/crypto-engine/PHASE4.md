## 2. 코인 홈 '엔진 공통 환경' 카드

분석(유료 AI)을 돌리지 않아도 보이는 **모든 코인 공통 입력**만 모았다. 데이터는 Phase 2 의 `/api/intel/context`(공개, CDN 5분 — 코인 분석과 같은 주소라 캐시 공유)라 서버 부담이 늘지 않는다.

| 영역 | 내용 |
|---|---|
| 거래 보류 · 다음 발표 | 지금 걸린 공통 보류(공식 발표 전후·위기 속보·FOMC 성명) + 다음 미국 주요 발표와 보류 구간(위험관리 설정의 전·후 분) |
| 유동성 | 스테이블코인 7일·30일, BTC·ETH 현물 ETF — 방향·유효기간 지나면 취소선 |
| 뉴스 충격 보드 | 해외 경제 뉴스 24시간 사건 묶음·확인 수준·주제(호재·악재 판단 없음). 주제 없는 연준 행정 공지는 뺀다 |
| 데이터 상태 | 공식 일정·DefiLlama·SoSoValue·연준 RSS·뉴스 RSS 정상/실패와 사유 |
| 코인별 마지막 엔진 판단 | 이 기기의 사전 기록에서 코인별 최신 상태·후보 쪽·몇 분 전 — 코인 분석 링크(자동 실행 안 함) |

오른쪽 위 배지: '공통 거래 보류 중'(빨강) / '공통 보류 없음'. 받기 실패 시 카드를 숨긴다(다른 코인 화면 영향 없음).

## 3. 하지 않은 것(이유)

- **백그라운드 알림**: 검증 전 엔진 상태로 알림을 보내면 실전 신호처럼 쓰이게 된다(명세 §8 — READY 를 실전 신호로 보이지 않게). 또 서버 주기 실행은 Vercel Hobby CPU 예산·새 크론 금지 규칙에 걸린다. 판정 30건 뒤 성과를 보고 따로 결정.
- **코인별 실시간 엔진 상태**: 기술·파생 입력이 분석 응답에 있어 홈에서 만들 수 없다 → 마지막 기록만 보여 주고 '기록 당시 판단'이라고 표시.
- 기존 주식·경제 캘린더·매매일지·시뮬레이터는 손대지 않았다.

## 5. 남은 것(엔진 전체)

- **독립 성과 검증: 아직 없음.** 판정 끝난 엔진 선택 30건이 모이면 기준선(전체 후보)·엔진이 거른 후보와 비교한다. 그 전에는 가중치·기준값을 바꾸지 않는다.
- 뉴스·연준 발언 방향 점수(원문·시장 반응 확인 계층), 서버 쪽 고른 간격 기록, 실제 체결 슬리피지·계좌 잔고 연결, 알림 — 성과 확인 뒤 결정.
