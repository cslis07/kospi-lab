- 확인 수준: **공식 자료**(연준 등 1차 출처) / **복수 보도**(다른 매체 2곳 이상) / **단일 보도·미확인**.

## 6. 발견한 점

- **PPI 가 기존 '임박 이벤트'에서 빠져 있었다**: 캘린더에서 PPI 중요도가 '중간'이라 분석 응답의 이벤트 필터(중요도 '높음'만)에 걸리지 않는다. 기존 판정 규칙은 바꾸지 않고, 엔진만 공식 일정을 직접 받아 PPI·PCE 등도 발표 전후 보류하게 했다. 기존 판정 엔진 쪽 보완 여부는 사용자 결정 사항.
- 거시 기준일이 11-10(실질금리)이라 **11-14(토) 09:00 KST 이후 4일 유효기간을 넘겨 '거시 입력 누락 → 거래 보류'**가 될 수 있다(Phase 1 에서 적은 보수적 동작이 실제로 나타날 시점).
- 뉴스 주제 분류는 제목 단어라 '인도 물가…금리 인상론'이 연준·금리로 묶이는 등 거칠다. 방향 점수에 쓰지 않으므로 표시용으로만 둔다.

## 7. 미완료

- **독립 성과 검증: 아직 없음.** 유동성 기준(±0.5%·±0.3)·안전모드 2시간·위기 단어 목록 모두 임시값.
- 뉴스·연준 발언의 **방향 점수**: 원문 확보·발언 문맥·시장 선반영(국채·달러·나스닥 반응) 확인 계층이 필요 — 연설 원문 페이지 수집 + 사람이 확인한 라벨 장부부터.
- 거래소 BTC·ETH 잔고·현물 순유입(CoinGlass 등)은 유료 계약이 없어 연결하지 않음.
- 레코드 표준화(§2-3: value·unit·observedAt·ingestedAt·revision·vintage) — 지금은 관측값에 `availableAt`·출처·유효기간, 컨텍스트에 `ingestedAt` 까지. 리비전·빈티지 저장은 Phase 3 사전 기록 장부와 함께.
- Phase 3: 엔진 결정 사전 기록(evidence log) → 모의 선행테스트 판정 연결, 비용 반영 손익비를 추천 진입가 카드에도 표시, 실제 계좌 잔고 연결.
- 자동 주문: 만들지 않음.
