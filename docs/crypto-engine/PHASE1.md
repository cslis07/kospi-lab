기존 알고리즘(`coinAnalysis` 판정·백테스트·모의 선행테스트·BNF 봇)은 바꾸지 않았다.

### 첨부 프로토타입 코드 리뷰에서 고친 점
1. **지난 속보가 영구 차단되던 문제** — `blockUntil` 이 지난 속보(예정 시각 없음)가 "종료시각 미확인"으로 계속 막았다 → 지난 안전모드는 해제(테스트 추가).
2. **잘못된 비용**일 때 손익비 계산을 이어 가던 흐름 → 바로 무효 처리.
3. 화면 표기 분리: `READY` → **'조건 충족(실험)'**, `BLOCKED` → '거래 보류' 등(명세 §8-4).
4. 대기 사유 문장의 가격을 유효숫자 6자리로 표시.

## 5. 발견한 점

- **추천 진입가 카드의 손익비는 비용 전 값**이다. 손절폭이 좁은 자리(0.2~0.4%)는 수수료·슬리피지·펀딩 14bp 만으로 손익비가 절반 가까이 줄어든다(테스트: 2.83 → 1.43). 엔진 패널에는 **비용 반영 손익비**가 나온다. 카드 쪽 표기 정리는 Phase 3 후보.
- 거시 기준일은 구성 값 중 가장 오래된 날짜(실질금리, 보통 2~3일 전)로 잡혀서, 연휴가 끼면 4일 유효기간을 넘겨 '거시 입력 누락 → 보류'가 될 수 있다(의도된 보수적 동작).
