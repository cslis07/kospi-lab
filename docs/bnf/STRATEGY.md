# BNF형 25일 이격도 역추세 — ETH 선물 백테스트 연구 규격

> 연구용 문서입니다. 실거래 주문·API 키·자동 진입 기능은 없습니다.
> 25일 이동평균 이격도를 쓰는 **BNF형(BNF 매매법에서 착안한)** 규칙이며, BNF 본인의 정확한 매매 알고리즘이 아닙니다.

이 문서는 결과를 보기 **전에** 고정한 규칙입니다. 결과를 본 뒤 규칙·임계값·판정 기준을 바꾸지 않습니다(최적화 금지).

## 1. 목적

- 목표는 높은 수익률이 아니라 **낮은 MDD와 일관된 기대수익**입니다.
- 기대수익이 비용 반영 후 음수이거나 표본이 부족하면 숫자를 미화하지 않고 각각 `사용 부적합`·`판단 불가`로 결론 냅니다.

| 펀딩비 | 공식 `monthly/fundingRate` 아카이브 (보조 지표로만 사용) | 공개 API 이력이 약 100일뿐 → **미포함** |

두 거래소의 OHLC·펀딩 데이터를 한 실험에서 섞지 않습니다.

### 2.1 15분봉 스키마 (정규화 후)

| 필드 | 형식 | 설명 |
|---|---|---|
| `t` | int (ms, UTC) | 봉 시작 시각(open_time). 15분 경계 정렬 |
| `o,h,l,c` | float | 시가·고가·저가·종가 |
| `v` | float | 거래량(기초자산 수량) |

### 2.2 검증 (하나라도 실패하면 수집기가 멈춥니다)

1. 월별 zip 의 SHA256 이 공식 `.CHECKSUM` 과 일치합니다(Binance).
2. `open_time` 은 오름차순이고 15분 경계에 정렬되어 있습니다. 중복은 동일 값이면 1개만 남기고, 값이 다르면 오류로 처리합니다.
3. OHLC 범위가 맞아야 합니다: `l ≤ min(o,c)`, `h ≥ max(o,c)`, `l > 0`, `v ≥ 0`, `close_time = open_time + 899 999` (Binance).
4. 부분 봉은 제거합니다. `open_time + 15분`이 수집 시각을 넘는 봉은 쓰지 않습니다.
5. 결측은 보간하지 않습니다. 시작부터 **연속된 구간만** 쓰고, 첫 결측 직전 봉에서 멈춥니다. 결측 구간은 manifest 에 그대로 기록합니다.
6. 출처 URL·기간·행 수·원본 zip SHA256·정규화 CSV SHA256 을 `data/bnf/<거래소>/manifest.json` 에 기록합니다.

### 2.3 리샘플링

- 1h·4h·1d 는 15분봉을 UTC 경계(`floor(t / 주기) * 주기`)로 묶습니다.
- 묶을 때 시가는 첫 봉, 고가는 최대, 저가는 최소, 종가는 마지막 봉, 거래량은 합계를 씁니다.
- 묶음 안의 15분봉이 4·16·96개를 모두 채우지 못하면 부분 봉으로 보고 버립니다.

## 3. 전략 (롱 전용, 1포지션)

기호 정리:
- `D` 는 신호 봉이 속한 UTC 날짜입니다(봉 시작 시각 기준).
- `close_d` 는 날짜 `d` 의 일봉 종가입니다.

| 단계 | 정의 |
|---|---|
| 기준 SMA | `SMA25(D) = mean(close_{D-25} … close_{D-1})`. 완료된 직전 25개 일봉만 씁니다. 15분봉 25개로 대신하지 않습니다 |
| 이격도 | `deviation = close / SMA25(D) − 1`. 모든 시간봉에서 같은 일봉 SMA25 를 씁니다 |
| 일봉 이격도 분포 | `devDaily(d) = close_d / SMA25(d) − 1` |
| 과매도 임계값 | `Q10(D)` = `devDaily(D-365 … D-1)` 365개의 10% 분위수(선형보간, type 7). 당일과 미래는 빼고, 365개가 모두 있을 때만 계산합니다 |
| 과매도 | 봉의 `deviation ≤ Q10(D)` |
| 후보 신호 | 최근 4개 봉(현재 봉 포함, `i−3 … i`) 중 과매도가 1개 이상 있고, **현재 봉 종가 > 직전 봉 고가**일 때 |
| 확정·체결 | 신호 봉 종가에서 확정하고, **다음 봉 시가 × (1 + 슬리피지)** 에 매수합니다. 같은 봉 시가 체결은 금지입니다 |
| 약세장 한정 | `close_{D-1} < SMA200(D) = mean(close_{D-200} … close_{D-1})` 일 때만 신호를 받습니다 |
| 손절 | `ATR14` 는 신호 봉 종가 시각까지 **완료된** 4시간봉의 Wilder ATR(14)입니다. 손절 거리는 `1.5 × ATR14 / 진입가` 이고, 1.2% 미만이면 1.2% 로 올립니다. **8% 를 넘으면 건너뜁니다** |
| 목표 | 진입가 + 1.8R (`R = 진입가 − 손절가`) |
| 최대 보유 | 72시간. 진입 후 72시간째 15분봉 **시가**에서 먼저 청산합니다 |
| 대기 | 청산 시각부터 24시간 동안 새 진입을 받지 않습니다 |
| 포지션 | 한 번에 1개, 롱만 엽니다. 보유·대기 중에 나온 신호는 버립니다 |

> 참고: 이 규칙은 과매도 뒤 반등을 노리는 역추세 **롱** 규칙입니다. 숏 규칙은 정의하지 않았습니다(양방향 혼용 금지).

### 3.1 청산 시뮬레이션 (모든 시간봉 공통, 15분봉 경로로 판정)

진입 봉부터 15분봉을 하나씩 다음 순서로 확인합니다.

1. 봉 시작 ≥ 진입 + 72h → **시가 청산** (시간 만기, 가장 먼저 처리)
2. 시가 ≤ 손절가 → **시가 체결** (갭 하락, 손절가보다 불리한 실제 시가)
3. 저가 ≤ 손절가 → 손절가 체결. 같은 봉에서 목표가도 닿았다면 **손절 우선**
4. 시가 ≥ 목표가 → 목표가 체결 (갭 상승의 유리한 시가는 쓰지 않음, 보수적)
5. 고가 ≥ 목표가 → 목표가 체결
6. 데이터가 끝나면 마지막 종가에 청산하고 `data_end` 로 표시합니다

모든 청산가에는 슬리피지를 불리한 쪽으로 반영합니다(`× (1 − 슬리피지)`).

청산 시각은 다음과 같이 잡습니다.
- 시가 체결이면 그 봉의 시작 시각입니다.
- 봉 안에서 체결되면 그 봉이 끝나는 시각입니다.

## 4. 체결·위험 가정 (설정 가능한 기본값)

| 항목 | 기본값 |
|---|---|
| 편도 수수료 | 0.05% (진입·청산 명목가 각각) |
| 슬리피지 | 0.02% (진입·청산 각각, 불리한 방향) |
| 초기 자본 | 1,000 USDT (기간마다 새로 시작) |
| 1회 위험예산 | 진입 직전 자산의 0.5% → `수량 = 위험예산 / R` |
| 증거금 상한 | 자산의 25% → `명목가 ≤ 0.25 × 자산 × 레버리지` |
| 레버리지 | 5x, 10x 비교 |

- **청산가·유지증거금·파산 확률은 모델링하지 않습니다.** 예상 청산가는 만들지 않고, 진입 대비 최대 역행(MAE)만 사실값으로 표시합니다.
- 손절 거리가 최소 1.2% 이므로 위험예산으로 정한 명목가는 최대 `0.5% / 1.2% ≈ 41.7%` 입니다. 이 값은 5x 상한(125%)과 10x 상한(250%) 모두보다 작습니다. 그래서 **이 규칙에서는 레버리지가 손익을 바꾸지 않고 사용 증거금만 바꿉니다.** 이 점은 결과에도 그대로 표시합니다.
- 기본 수익률은 **수수료·슬리피지 반영, 펀딩비 제외**입니다.
- Binance 실험에서는 공식 펀딩비를 반영한 수익률을 보조 열로 따로 표시합니다.
  - 보유 중 `calc_time` 을 지날 때마다 `−수량 × 해당 시각 15분봉 시가 × 펀딩비` 를 더합니다.
  - 명목가는 공식 mark price 가 아니라 15분봉 시가로 근사합니다.

## 5. 검증 기간

| 구간 | 진입 시각 기준 |
|---|---|
| 개발·탐색 | 첫 유효 신호 ~ 2024-10-31 23:59 UTC |
| OOS 검증 | 2024-11-01 00:00 UTC ~ 데이터 끝 |
| 전체 | 첫 유효 신호 ~ 데이터 끝 |

- 첫 유효 신호는 약 2022-11 말입니다. 365일 분위수 계산에는 `25 + 365`일의 선행 데이터가 필요합니다.
- 각 구간은 1,000 USDT 로 따로 시뮬레이션합니다.
- 구간 끝 직전에 진입한 거래는 실제 데이터로 청산될 때까지 따라갑니다. 매개변수를 최적화하지 않으므로 누출이 아닙니다.
- 금지 사항: 미래 데이터 누출, 신호 봉 시가 체결, 미래 ATR 사용, 최적화 후 같은 구간 재평가.

## 6. 출력 지표 (구성별)

- 출력 구성은 `15m / 1h / 4h / 1d` × `전체 국면 / 약세장 한정` × `5x / 10x` × `개발 / OOS / 전체` 입니다.
- 지표 목록: 거래 수, 승률, PF, 평균 R, 평균 보유시간, 단일 거래 최대 손실(USDT·R), MTM 최대낙폭, 전체 수익률, 월별 수익률, 최대 연속 손실, 수수료 합계, 슬리피지 비용 합계, 건너뛴 신호(손절 > 8%) 수.
- 승패는 비용 반영 순손익이 0보다 크면 승으로 셉니다(펀딩 제외).
- `R` 은 순손익을 계획 위험액(`수량 × (진입가 − 손절가)`)으로 나눈 값입니다.
- MTM 낙폭은 15분봉 종가마다 평가한 자산의 고점 대비 최대 하락률입니다.
- 월별 수익률은 UTC 월말 MTM 자산 기준입니다.

## 7. 판정 기준 (결과 보기 전 고정)

판정은 각 구성의 **OOS 구간**을 기준으로 하며, 수수료·슬리피지는 반영하고 펀딩은 제외합니다.

1. OOS 거래가 30회 미만이면 → **판단 불가**
2. OOS PF < 1.0 또는 OOS 평균 R ≤ 0 이면 → **사용 부적합 (기대수익 음수)**
3. OOS MTM 최대낙폭 > 10% 이면 → **사용 부적합 (낙폭 과다)**
4. OOS PF < 1.2 이면 → **사용 부적합 (우위 미약)**
5. 개발 구간(거래 30회 이상)의 평균 R ≤ 0 이면 → **사용 부적합 (기간 간 불일치)**
6. 펀딩 반영 OOS 평균 R ≤ 0 이면 → **사용 부적합 (펀딩 반영 시 음수)** (Binance 만 적용)
7. 위 조건에 하나도 걸리지 않으면 → **추가 검증 후보**
   - 여기서 끝나지 않습니다. 실거래 적합 판정이 아니며, 별도 선행(포워드) 테스트가 필요합니다.

전체 결론은 다음과 같습니다.
- `추가 검증 후보` 가 하나도 없으면 전략 전체를 **사용 부적합**으로 결론 냅니다.
- 30회 미만 구성만 남으면 **판단 불가**로 결론 냅니다.
