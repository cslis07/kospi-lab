## 함께 고친 401(잠긴 기기)

공개 화면에서 잠금 확인 없이 계좌 API 를 부르던 곳 3개 — 코인 분석 계좌 맥락(`/api/bitget/positions`), 상관관계 표, 폭락 카드의 '실전 성적'(`/api/bitget/alert-log`). 잠긴 브라우저 코인 분석 401 0·콘솔 오류 0 [확인됨].
자산·계좌·매매일지·복기 화면은 원래 401 로 잠금 안내를 띄우는 개인 화면이라 그대로 둠.
