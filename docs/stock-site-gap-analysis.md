## 4. 원칙 (모든 추가 기능 공통)

- 비공식 무키 API는 형식이 바뀌면 빈 값 → 카드째 숨김(지어낸 숫자 없음). 파서는 단위 테스트로 고정.
- 목표주가·계절성·신고가는 "예측·신호 아님" 문구를 화면에 함께 표시.
- 계산은 표시용(괴리율·전년 대비·월 수익률)만. 기존 측정·신호 정의·모의 테스트 규칙은 건드리지 않음.
